# Layoffs Data Cleaning Project
This project focuses on cleaning the World Layoffs dataset using SQL.
## Project Overview
- Removed duplicate records
- Standardized company names, locations, and industries
- Handled null and blank values
- Removed unnecessary rows and columns
## Files
- `data_cleaning.sql.sql` → SQL script used for cleaning
- `Layoffs_raw.csv` → Original raw dataset
## Tools Used
- MySQL
